# Office Attendance Frontend

Frontend de la aplicación de control de asistencia a oficina.

## Tecnologías

- React
- TypeScript
- Vite
- date-fns
- Vitest
- Testing Library

## Requisitos

- Node.js 20+
- npm

## Despliegue en Vercel

La API serverless vive en el mismo proyecto de Vercel. Configura `DATABASE_URL` en Vercel con la cadena de conexión de Neon; el frontend usa `/api` automáticamente.

## Tests

```bash
npm test
```
